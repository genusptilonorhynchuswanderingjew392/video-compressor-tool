## Features

- H.264 and H.265 (HEVC) encoding — up to 70% smaller files
- Target file size mode — set exact output size
- Batch compress entire folders at once
- Hardware acceleration via NVIDIA NVENC and AMD AMF
- Preview quality before committing to compression

## FAQ

**Will compression visibly reduce quality?**  
At High quality preset, the difference is virtually invisible. Medium reduces size by ~50% with minor quality loss.

**Can it handle 4K video?**  
Yes, though compression of 4K files takes significantly longer without NVENC/AMF hardware acceleration.

## Requirements

- Windows 10 / 11 (64-bit)
